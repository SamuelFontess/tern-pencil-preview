# AGENTS.md

Tern plugin (Luau) that previews pen.dev `.pen` designs. Read the spec before changing behavior:
`docs/superpowers/specs/2026-10-13-tern-pencil-preview-design.md`; the task list is
`docs/superpowers/plans/2026-10-13-tern-pencil-preview.md`. Both are local working notes, ignored by
git and not published.

## Gate

```
python scripts/gate.py
```

Type-checks every non-test `.luau` with `luau-lsp analyze --definitions=tern.d.luau` (any
diagnostic fails, lint included) and runs `luau tests/run.luau`. Tools: `$LUAU_TOOLS`
(default `D:/tools/luau`). `tern.d.luau` is generated by `tern plugin types .` and is not committed.

## Conventions

- Every `.luau` file starts with `--!strict`. Modules: `require("./lib/x")`, relative to the caller.
- Tabs for indentation, as in the Tern SDK examples.
- Pure logic lives in `lib/`; `host.luau` and `window.luau` wire it to Tern.
- Unit tests in `tests/*_test.luau`, registered in `tests/run.luau`; they install the `tern` stub from
  `tests/stub.luau` and never touch the real Tern API or network.
- Processes only through `tern.process.run` with a callback and `timeout_ms`; never block the host
  (2 s per call). The plugin never writes the user's `.pen`.
- Tests assert behavior, not wording or wiring.
